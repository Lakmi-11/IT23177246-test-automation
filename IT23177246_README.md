# Playwright Test Automation Project
**Student IT Number:** IT23177246

## Project Overview
This project contains automated test cases for the PixelsSuite PNG converter tool. It verifies the image preview functionality using Playwright.

## Installation
To install the necessary dependencies, run:
```bash
playwright install chromium
```

## Running the Tests
To execute the automation script, use the following command:
```bash
python IT23177246_image_preview_test.py --png IT23177246_sample.png --csv IT23177246_execution_results.csv --out-dir IT23177246_results
```

## Included Files
- `IT23177246_image_preview_test.py`: Main automation script.
- `IT23177246_execution_results.csv`: Test execution summary.
- `IT23177246_Manual_Test_Cases_Option_2.xlsx`: Manual test case documentation.
- `IT23177246_git_link.txt`: Link to the GitHub repository.
- `IT23177246_sample.png`: Sample image used for testing.
- `IT23177246_results/`: Folder containing screenshots of test results.
